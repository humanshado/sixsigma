# Example datasets

| File | Description | Use with |
|---|---|---|
| ball_bearings.csv | Millions of revolutions to fatigue failure for 23 deep-groove ball bearings (Lieblein & Zelen, 1956; a classic public-domain dataset). The Weibull fit is shape 2.10, scale 81.9 | Reliability analysis |
| pump_field_failures.csv | Simulated field data: operating hours of 40 pumps installed at different times; "Failed" units failed, "Running" units are right-censored | Reliability analysis with censoring |
| attribute_agreement.csv | Simulated study: 3 appraisers rate 20 parts as Pass/Fail twice; the Standard column holds the known correct answer | Attribute agreement analysis |
