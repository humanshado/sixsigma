# Changelog

## 1.0.0

- **Production readiness:** in-app help on every screen and a getting-started guide; validation suite
  (51 checks against published reference results) with a report and reference datasets; launchers for
  Windows, macOS and Linux; Dockerfile and deployment guide; uploads up to 200 MB; fast control charts,
  regression plots, life data, non-normal capability and Kaplan-Meier for 100,000+ rows; undo history
  capped by memory.
- **Batch 4:** multiple worksheets with per-worksheet undo/redo, append and join; DMAIC menu (project
  charter, SIPOC, 5 Whys, value stream map, control plan, A3 report).
- **Batch 3:** blocking, general full factorial, split-plot, definitive screening, D-optimal and
  extreme-vertices mixture designs; design power; tolerance stack-up; Monte Carlo simulation; Reliability
  menu with accelerated life testing, warranty analysis and demonstration test planning.
- **Batch 2:** more control charts and run rules, capability extensions, logistic/stepwise/best subsets
  regression, general ANOVA with random factors, expanded Gage R&R, statistics extensions.
- **Batch 1:** reliability, acceptance sampling, attribute agreement, sample size and power, projects and
  reports, data tools, FMEA.
- **Initial version:** worksheet, basic statistics, hypothesis tests, regression, factorial DOE, capability,
  control charts, Gage R&R, Pareto and other quality tools; features from qcr and r6qualitytools.
